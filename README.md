# Huikang (Will) Ye

Personal academic website: https://willye45.github.io/

## Files

- `index.html`: biography, education, research, publications, animations, and contact information.
- `cv.html`: web CV with print / save as PDF support.
- `styles.css`: shared responsive layout, typography, animation, and print styles.
- `site.js`: mobile navigation, animation pause/play controls, and CV printing.
- `assets/favicon.svg`: website icon.

## Updating the website

Edit the HTML, CSS, or JavaScript files and push changes to `main`. GitHub Pages publishes the repository root automatically. No package installation or build step is required.

## Local preview

Run `python -m http.server 4173` from this directory and visit http://localhost:4173/.

The publication animations have independent pause/play controls and respect the reduced-motion preference.
